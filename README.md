# OuroborosChat

OuroborosChat is a self-referent chat app.
It works by modifying itself on GitHub.

## Requirements

- `bash`
- `git`
- GitHub CLI - `gh`
- `base64`

## Initialization

```bash
gh repo clone r-flash/OuroborosChat
```

## Usage

Run:
```bash
chmod +x OuroborosChat.sh && ./OuroborosChat.sh
```

Then write your message.
